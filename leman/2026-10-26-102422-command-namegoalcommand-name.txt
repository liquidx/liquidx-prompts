⏺ All green across the whole suite. The work is complete — here's a summary.

  Done: web links in chat are highlighted and tappable

  What was already there: markdown-style links ([text](url)) in agent prose
  rendered in accent color and opened the browser via ACTION_VIEW (wired in
  LemanNavHost.kt:146).

  What was missing, now fixed (TDD, red → green for each):

  1. Bare URLs weren't links at all. A plain https://… pasted into chat rendered
     as inert text. I added commonmark's autolink extension
     (commonmark-ext-autolink, same version as the other commonmark artifacts)
     to the shared parser in BlockSegmenter.kt, so bare URLs now parse as Link
     nodes and automatically get the existing accent highlight + tap-to-open
     treatment everywhere markdown renders.
  2. Links in user, system, and collapsible content were dead. UserTurn,
     SystemTurn, and CollapsibleBlock rendered MarkdownBody without a link
     callback, so links there were styled but tapping did nothing. Each now
     takes an onLinkClick parameter, AgentTurn forwards it into collapsible
     blocks, and ThreadScreen passes the navigation-level handler (which
     launches the browser) into user and system turns.

  Tests:
  - InlineTextTest (new) — bare URLs produce a clickable annotation over exactly
    the URL text, styled with the accent color, invoking the callback with the
    URL; markdown links and plain prose covered as regressions. Watched the
    bare-URL cases fail before implementing.
  - ThreadViewLinkTest (new, Robolectric Compose) — tapping a link inside a user
    turn, an expanded system turn, a collapsible block, and a collapsible
    inside an agent turn each fires the callback with the URL.
  - Full testDebugUnitTest suite passes, so the parser change didn't regress
    block segmentation or screenshots.
